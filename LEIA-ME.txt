S4INTH IMPORTS - Primeira oferta afiliada

1. No GitHub, abra seu repositorio da loja.
2. Substitua o arquivo products.js da raiz pelo products.js desta pasta (Add file > Upload files ou edite o arquivo existente).
3. Clique em Commit changes. O site publicado pelo GitHub Pages deve atualizar apos a publicacao.
4. O arquivo index.html acompanha o pacote caso voce ainda nao tenha a versao original; nao precisa substituir o seu se ele ja for igual.

IMPORTANTE: O nome e preco do produto nao foram identificados a partir do link curto; por isso o cadastro mostra 'Oferta AliExpress #1' e 'Consultar preco no AliExpress'. Para alterar, edite name, price, category e image em products.js.

Se voce ja adicionou produtos no navegador usando o painel de gerenciamento, a lista salva localmente pode sobrescrever o catalogo publicado. Para conferir a versao publica, abra o site em uma janela anonima.
